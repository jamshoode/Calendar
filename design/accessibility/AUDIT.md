Accessibility audit checklist.

- Color contrast: ensure WCAG AA for text and UI elements.
- Dynamic type: support all sizes without truncation.
- VoiceOver: labels for tappable elements, correct reading order.
- Hit target size: >= 44pt where interactive.
- Semantic order: logical navigation for assistive tech.
- Localization: layout adapt for RTL.

Fixes:
- Use tokens for color pairs.
- Test with Accessibility Inspector and VoiceOver.
