Component library — minimal, reusable components.

Components:
- NavBar: title, compact controls
- CalendarGrid: month/week/day modes, selectable cells
- EventCard: title, time, color dot, subtle shadow
- AgendaList: compact list with time and title
- FAB (Quick Add): circular, bottom-right
- Modal: sheet for create/edit event
- Input: single-line, date/time pickers
- Widget components: small/medium/large variants, compact timeline

States:
- default, hover/pressed, disabled, selected
Usage:
- Compose components with tokens from design-system.
